## Regra de precedência

Em caso de conflito:

1. instrução explícita mais recente do responsável pelo projeto;
2. `AGENTS.md`;
3. contratos desta pasta, na ordem acima;
4. implementação existente.

Nenhum requisito deve ser removido silenciosamente. Mudanças aprovadas precisam atualizar o contrato correspondente.
