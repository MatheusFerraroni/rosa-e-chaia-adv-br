# 00. Visão geral do projeto

## Produto

Site institucional do escritório de advocacia **Rosa e Chaia**.

## Objetivo

Apresentar o escritório, suas áreas de atuação, seus profissionais e canais de contato com clareza, sobriedade e credibilidade.

## Plataforma

- site estático;
- repositório Git;
- hospedagem no GitHub Pages;
- domínio próprio;
- HTML, CSS e JavaScript;
- Bootstrap local;
- estilos customizados carregados sobre o Bootstrap.

## Restrições principais

- não usar CDN;
- não depender de servidor de aplicação;
- não armazenar segredos no repositório;
- não publicar dados jurídicos ou institucionais não confirmados;
- não alterar a identidade visual sem aprovação.

## Fora do escopo inicial

- área do cliente;
- autenticação;
- banco de dados;
- painel administrativo;
- chat em tempo real;
- pagamento;
- automações jurídicas;
- formulário com backend próprio.
